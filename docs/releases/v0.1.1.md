# Sim Telemetry Engineer v0.1.1

Esta versão melhora a instalação e a apresentação do projeto para jogadores. O app Lua
continua funcionando sem Python e sem alterar o setup do carro.

## Novidades

- ZIP pronto para instalar publicado diretamente na GitHub Release;
- README simplificado, com download e instalação em primeiro lugar;
- explicação clara de que Python não é necessário para usar o app no jogo;
- documentação técnica, análise pós-sessão e instruções de desenvolvimento separadas;
- badges de versão e downloads no repositório.

## Instalação

1. Baixe `sim-telemetry-engineer-v0.1.1.zip` nos assets desta release.
2. Extraia a pasta `sim_telemetry_engineer` para:
   `assettocorsa\apps\lua\sim_telemetry_engineer`.
3. Inicie uma sessão com Custom Shaders Patch.
4. Abra **Sim Telemetry Engineer** na barra de apps à direita.

## Observação

Não há mudança no comportamento do mapa em relação à v0.1.0. O foco desta versão é a
distribuição do app e a documentação para jogadores.
